# 🍴 Recipe Collection

A simple **Streamlit recipe manager** for storing, searching, and managing recipes.

🔗 **Live app:** [recipe-manager-idk.streamlit.app](https://recipe-manager-idk.streamlit.app/)

## Features

- ➕ Add and manage recipes
- 🔎 Filter and search recipes
- 🎲 Get random recipes
- 🌐 Search recipes using TheMealDB
- ⭐ Rate recipes
- 🛒 Create shopping lists
- 📜 Track cooking history
- 👨‍🍳 Chat with an AI Smart Chef

## Data

Recipes are stored in `recipe.csv`, which is created automatically when the app runs.
